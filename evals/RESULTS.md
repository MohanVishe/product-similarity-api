# Retrieval eval results

_Generated by `python -m evals.run_eval` from [`queries.json`](queries.json) and [`queries-heldout.json`](queries-heldout.json); numbers in [`results.json`](results.json). Do not edit by hand — CI runs `python -m evals.run_eval --check`._

- Catalogue: 16 products · dense: `all-MiniLM-L6-v2`, cosine (similarity = 1 - distance, rounded to 3 dp as the API returns it) · keyword: BM25Okapi (rank-bm25) over name + category + description, same normalisation · hybrid: reciprocal rank fusion, k = 60 (not tuned).
- Configurations: `dense`, `bm25`, `hybrid`; `+excl` = exclusion parsing on. **Before** = `dense` (the API until this change); **after** = `dense+excl` (the API default now).
- Default mode rule (fixed before the dev run: hybrid is the default unless, with exclusions on, it lowers dev-set MRR or recall@3 below dense; otherwise dense. The held-out set is not consulted.) → **dense**.
- Every query goes through `retrieval.search_detailed`, the function `/similar_products` calls. Metrics are over the top 3 (the API default `limit`) unless stated. Queries and judgments are author-written and small: these numbers describe this catalogue, not general retrieval quality.
- Negation accuracy = share of negation queries with no ruled-out product in the top 3. Off-topic FP = share of off-topic queries that get at least one product back. In `bm25` mode only products sharing a word with the query are returned.
